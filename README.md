# Go Starter

This project is a CLI music store application designed to practice and improve Go programming skills. It covers core concepts such as package organization, interfaces, structs, and interactive user input.

## Features

- Browse a catalog of artists, albums, and songs.
- Add items to a persistent shopping cart.
- Remove items from the cart.
- Simulate a checkout process with credit card validation.

## Project Structure

- **cart**: Management of the shopping cart and its items.
- **data**: Initialization and seeding of the music catalog.
- **helper**: Utilities for handling user input and terminal interactions.
- **model**: Core domain entities (Artist, Album, Song).
- **payment**: Logic for simulating payment transactions.
- **ui**: Interface logic for displaying menus and handling navigation.

## Usage

Ensure you have Go installed on your system. To run the application, navigate to the project directory and execute:

```bash
go run main.go
```
